知识创作者与 B 端触达实测（2026-11-25）

原文：飞书知识库（revision 3，2026-11-26 19:37 修改）

抽样日期：2026-11-25。照 webdesign.so 的冷启动套路（程序判断对方缺视频 → 先做好样片 → 拿公开联系方式去敲门），对国内外 7 类知识创作者抽了约 1,250 个真实对象，对 B 端机构抽了 196 个，用脚本和公开页面逐个检查。本轮只测到“能拿到联系方式”，没有发出任何一条消息。原始 HTML 报告附在本节点下。

结论： 创作者侧最好做的是中文播客：小宇宙节目页上有主播自己填的联系方式，51% 留了邮箱，68% 留了邮箱或个人微信；B 站抽查约 74% 没有像样的视频版本，每 100 个节目里大约能挑出 50 个“缺视频且联系得上”的目标。其次是英文播客（69% 有可用邮箱，约 46% 没有 YouTube 频道）。B 端最值得先做的是 YC 早期 SaaS、国内中小 ToB SaaS 和海外律所、会计事务所；电商平台对脚本全部拦截，程序化不可行。

“每 100 个能敲门的”等于缺视频率乘以联系方式率，粗略地把两者当作互不相关，只用来排序。缺视频的判定方法：中文播客看 B 站同名账号或主播账号是否少于 10 条视频；英文播客看 YouTube 搜索结果里有没有同名频道；论文看项目页有没有视频；GitHub 看 README 有没有 GIF 或视频；Substack 看最近 25 篇有没有视频帖；Gumroad 看商品页有没有视频封面。

2. 每类怎么找、怎么联系、卡在哪

中文播客（推荐先做）

  • 找人：xyzrank.com/api/podcasts 直接返回 8,210 个节目，带类目、排名、小宇宙链接和 RSS。在前 1000 名里按商务、科技、历史、教育、投资等类目筛出 349 个。
  • 联系方式： 小宇宙节目页的数据里有主播自己填的联系方式列表（邮箱、微信、公众号、微博、即刻）。349 个里 179 个有邮箱，145 个有个人微信，269 个（77%）至少填了一种。邮箱多是 163、Gmail、QQ 这类个人邮箱，平台统一邮箱很少。这是主播主动公开的联系入口，合规上最干净。
  • RSS 里的主播邮箱字段： 不托管在小宇宙的节目 70 个里有 62 个；托管在喜马拉雅的 65 个里只有 22 个。小宇宙托管的 RSS 对脚本返回 403，没有绕过，改读公开节目页。
  • 判断缺视频： B 站搜索接口对脚本返回 412 风控，没有绕过，改用浏览器像普通用户一样搜了 19 个：11 个没开账号，3 个有账号但只发过 6 条以内（忽左忽右、小天章都属于这一档），5 个在正常更新。排名靠前的大节目也大多没做视频。
  • 样片： 挑一期做成带字幕的讲解视频或 3 条切片，邮件或加微信时附上可撤回的链接。

英文播客

  • 找人： iTunes Search API 免费、不用密钥，直接给出 RSS 地址。Podcast Index 网页返回 403，没有用上。
  • 联系方式： 548 个 RSS 全部能读到，其中 450 个有主播邮箱字段。去掉 anchor.fm、acast 的平台转发地址（47 个）和 BBC、NPR 等大媒体（44 个），剩下 378 个（69%）是个人或小工作室邮箱。
  • 判断缺视频： 读 YouTube 搜索结果页，54 个里 29 个有同名频道。匹配规则偏保守，实际缺视频的比例可能略低于 46%。
  • 注意： RSS 里的主播邮箱本来是留给 Apple 联系用的，拿来做营销属于灰色地带。邮件要一对一发送，带退订链接，第一封就附上样片。

论文作者

  • 用 arXiv API 取最新 40 篇，读论文首页：26 篇（65%）有作者邮箱。15 篇附了项目或代码链接，其中只有 5 篇项目页有视频，基本都是计算机视觉方向的效果演示，不是讲解视频。
  • 缺口大，时机也明确（投稿期和会议宣传期）。但学术邮箱收到营销邮件很容易反感，一旦被标成垃圾邮件会连累发信域名。建议只挑 AI 方向、有项目页的论文，每周 5–10 篇，直接送做好的 1–3 分钟讲解视频，不推销产品。

开源维护者

  • 用 GitHub 搜索取近 4 个月新建、100–3000 星的 60 个仓库：23 个 README 有 GIF 或视频，49 个的提交记录里有真实邮箱。
  • GitHub 使用条款明确禁止拿 GitHub 上收集的用户信息发垃圾邮件或做营销，所以提交记录里的邮箱不能用。只算个人主页上主动公开的邮箱是 28%，有 X 账号的是 30%，实际能做的规模比数字看上去小得多。

Substack / Newsletter

  • Substack 的公开类目接口能列出各类目的头部刊物。7 个知识类目共 525 个，抽 80 个查最近 25 篇：17 个发过视频，79% 没有。
  • 公开联系方式少：接口不返回作者邮箱，About 页留了邮箱的只有 20%，加上有 X 账号的也只有 38%。最常见的联系路径是“订阅后直接回复邮件”，这一步要用真实邮箱订阅，本轮没做。

课程作者（Gumroad）

  • Gumroad 搜索接口返回 JSON。60 个课程类卖家里，商品页有视频的只有 11 个（18%）；能找到邮箱的 17 个（28%）。
  • 缺口最大，但联系方式少，卖家质量参差不齐；他们需要的宣传片偏营销，和“知识讲解”不完全对口。

国内图文作者（公众号、知乎、小红书）

  • 没有能程序化列出作者和联系方式的公开入口。公众号不能给陌生人发私信；知乎、小红书的私信有数量限制，批量发容易触发风控。这和现有《图文作者触达手册》的判断一致：只能人工、小批量，走作者公开的商务邮箱或平台自带的私信。

3. B 端：哪些机构也需要知识讲解视频

结论： B 端里“程序判断缺视频 + 找到公开联系方式”这条路能走通的，是 YC 早期 SaaS、国内中小 ToB SaaS 和海外律所、会计事务所。电商平台（淘宝、1688、抖店、大众点评、小红书）和 Shopify 商品接口对脚本全部拦截，程序化不可行。共抽 196 个，能判定的 141 个。

  • “缺视频”的口径要小心： YC 样本 100% 没有嵌入 YouTube 或 Vimeo，但 46% 在官网自己放了 mp4。这些视频有的只是首屏的装饰动画，有的就是产品讲解（比如叫 HIW.mp4 的“How it works”）。表里用的是保守口径“完全没有视频”。要准确判断，还得看 mp4 的时长、有没有声音。另外，国内厂商的视频常放在 B 站、视频号上，只看官网会误判。
  • 名单来源： YC 公司来自 yc-oss 公开的 JSON（共 6,408 家，筛到 1,330 家后随机抽样），每家都带一句话介绍和长描述，可以直接当样片素材。海外本地服务来自 OpenStreetMap 的公开查询接口；Justia、Clutch 两个律所/会计目录返回 Cloudflare 403，已停用。国内 SaaS、教培、律所的名单是按领域手工列的，偏头部机构；国内网站经代理访问大量超时，这是网络问题，需要换国内网络出口重测。
  • 和创作者侧比： B 端有营销预算，更愿意付钱；官网邮箱和表单是合规的商务入口。但决策链更长，样片要贴着对方的产品做、没法批量复用，表单和电话也只能人工处理。
  • B 端额外的合规点： 国内不能电话外呼、不能群发短信，优先发企业公开邮箱。加拿大 CASL 最严；德国等地连 B2B 冷邮件也要求事先同意。律所和医疗行业有广告规范，样片不能替对方承诺疗效或胜诉。
  • 样本小： 每类只有 7–27 个能判定，误差大约正负 15–20 个百分点。静态抓取会漏掉网页脚本加载的视频和预约插件，所以缺视频率偏高、表单率偏低。各类机构的付费意愿基本是推断。

4. 合规与边界

  • 和现有手册的冲突： 《图文作者触达手册》写的是“只用作者主动公开的商务入口，不买、不猜、不抓取”。按这条：小宇宙主播自填的联系方式、个人主页或 About 页公开的邮箱可以用；RSS 里的主播邮箱算灰色；GitHub 提交记录里的邮箱不能用。如果要用脚本批量收集，需要先改手册的口径。
  • 海外： 美国 CAN-SPAM 要求写明真实发件人、地址，并提供退订方式。收件人在欧盟适用 GDPR，冷邮件要能说明“正当利益”，并允许对方要求删除；加拿大 CASL 更严。
  • 国内： 个人邮箱和微信号属于个人信息，《个人信息保护法》要求处理有合法依据，而且只能用于对方公开时的用途（合作联系）。加微信要人工逐个加。
  • 样片版权： 拿别人的内容做样片属于未授权改编，只能一对一发给本人看，不能公开发布。
  • 本轮没有绕过任何限制： 小宇宙托管的 RSS 返回 403、B 站搜索接口返回 412、Podcast Index 返回 403、Shopify 和各电商平台的拦截，都改走公开页面或直接放弃。

5. 还没测的：真发出去有没有人回

到这一步只证明了“找得到人、拿得到联系方式”，“发出去能不能收到回复”要真发才知道。最小测试方案如下：

  1. 中文播客 10 个、英文播客 10 个、YC 公司 10 家，先给每个做好一条样片，用一个新的发信子域名一对一发送，邮件带退订链接。
  2. 记录送达、打开、回复、退订，两周后看回复率。这批只用来判断能不能放大，不用来估算转化率。
  3. 发信是以用户名义对外发消息，需要先确认收件人名单、样片和邮件文案。2026-11-25 已决定暂不发送。

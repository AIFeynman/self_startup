# 每日增长 Case：源评估与方案（设计稿 2026-11-02）

> 目标：每天自动挑 1 个**真实的**用户增长案例拆给我看，学「怎么把产品送到目标用户面前、拉新、留住」。
> 与已有「生意拆解卡」（`_intel_startup.PROFILE_PROMPT`，以公司为单位、讲怎么赚钱）的区别：这里以**一次增长动作 / 一段增长故事**为单位，重点是渠道、执行细节、激活与留存，以及我能照着跑的小实验。

## 0. 完成标准

| # | 标准 | 怎么验 |
|---|---|---|
| G1 | 每天 1 张 Case 卡，10 点前生成；同一公司 90 天内不重复 | 连续 7 天有卡，公司不重复 |
| G2 | 每张卡讲的是具体公司 + 具体动作 + 至少 1 个数字，数字标 grade（verified / reported） | 卡片校验：节齐全、≥1 个带来源链接和日期的数字 |
| G3 | 每张卡有「我能怎么用」：一个一周内能跑的小实验 | 卡片校验该节非空 |
| G4 | 挑选是通用规则（打分 + 去重），不是给某个源调参 | 换一批源条目同样能选出卡 |

## 1. 源评估（2026-11-02 实测）

方法：直接拉 RSS 数近 30 天篇数、看标题；Reddit 走公开 RSS；HN 用 Algolia 查近一年；X 用项目已接的 GetXAPI 跑 5 组增长关键词搜索（约 $0.005），人工看前 8 条是不是「真 Case」。

### A 档：主力（一手、有数字、稳定更新）

| 源 | 近 30 天 | 实测样本 | 判断 |
|---|---|---|---|
| RevenueCat 博客 `revenuecat.com/blog/rss.xml` | 24 篇 | 「Praktika CEO 不喜欢的那条达人视频让它从 $1M 涨到…」、节日促销对订阅 App 的数据分析 | 订阅 App 实战 + 数据，最稳 |

| 源 | 判断 |

### C 档：不推荐当 Case 源

| 源 | 原因 |
|---|---|
| Reddit | 公开 RSS 稍并发就 429；r/startups 本周 Top 25 几乎全是提问、求助，不是 Case。最多当「早期冷启动 / 失败」样本 |
| Hacker News | 近一年标题含「first 1000 users / how we grew / $1M ARR」且 ≥50 分的，几乎 0 条 |
| 已停更或拿不到 | How They Grow（2026-02 后停更）、Growth Unhinged（迁到 beehiiv，旧 feed 停在 01-12，新地址待找）、Leah Tharin（07 月后停）；First Round Review / Indie Hackers / Starter Story / growth.design 没有可用的公开 RSS（404 / 403） |

**结论：X 适合当线索源，不适合当事实源。** 主力用 RevenueCat + Sub Club + Lenny（一手 + 带数字），X 只看名单账号，数字用 TrustMRR 核验。

## 2. 链路

```
采集（每天，复用 _feed_sources.fetch_rss / fetch_x）
  A/B 档 RSS 近 14 天条目 + X 名单账号近 3 天 ≥100 赞原创 + Sub Club 存档（候选池不够时）
→ 初筛（DeepSeek 批量打分，0–3 分 × 5 项）
  具体公司？有数字？讲了获客 / 激活 / 留存的具体动作？能迁移到 AI 产品？一手来源？
→ 去重：同公司 90 天内出过卡的跳过；同一故事多源合并成一个候选、来源都挂上
→ 选 1：总分最高；并列时 A 档源优先、有 TrustMRR 可核验的优先
→ 写卡（后台 Claude 任务，联网读原文 + 补第二来源）→ 校验节齐全 / 有链接日期 → 存（只追加）
```

## 3. Case 卡结构

1. **一句话**：谁，用什么动作，在多长时间里，把什么指标从 X 做到 Y
2. **背景与数字**：公司 / 产品 / 目标用户；每个数字带 grade（verified / reported）、来源、日期
3. **目标用户在哪**：他们原本在哪些渠道、什么场景下出现
4. **触达动作**：渠道、具体怎么做（素材、频率、预算、工具）、时间线
5. **激活与留存**：第一次用到价值的路径、留存 / 复购的机制（没有就写「来源没讲」，不编）
6. **为什么有效**：背后的机制（引用 Elena Verna / Andrew Chen 等方法论时注明）
7. **反例与风险**：什么条件下不成立、渠道衰退、口径问题
8. **我能怎么用**：一个一周内能跑的小实验（动作、量、看什么指标、怎么判成败）

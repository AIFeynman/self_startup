    完成标准工具描述不撑爆上下文，模型能稳定选对工具。

    为什么排这里工具描述本身要占上下文，所以排在上下文之后。

  5. Agent · 控制深

  6. Agent · 反馈深

    自纠错、自动验证、trace 评测，以及兜底的沙箱、权限、注入防护。

    完成标准自己的 Agent 在 Terminal-Bench 或你业务的评测上跑出可复现的分数（pass^k）。

    为什么排这里交出去多少控制权，取决于能不能验证；验证方法来自第 2 步。

  7. Agent · 积累中

    记忆、技能自积累、自改 harness；给自己的 Agent 加一条“跑完沉淀 Skill”的回路，用第 6 步的评测看它有没有变好。

    前置6；3 的记忆

    完成标准有一组前后对比：加了积累回路后，分数变了多少。

    为什么排这里没有可靠的反馈，就分不清该留下什么。

  8. AI for AI 与 RSI中

    用改什么、闭合到哪、靠什么信号三问，给每个自我改进的工作打标签。

    前置7；2

    完成标准一份带标签的工作清单，加一份玩家与时间线判断。

    为什么排这里第 7 步就是工程版的 RSI，有了它才看得懂这里在改什么。

  9. 多模态轻

    按表示、统一、可控三轴扫一遍；程序化视频动手做一次：让 Agent 写一个 Manim 视频，看渲染结果再修。

    为什么排这里可控轴的程序路线直接复用 Agent 的行动和反馈。

  10. 世界模型与具身轻

    按一致、交互、用途三轴扫一遍，再用 L1–L5 定级。

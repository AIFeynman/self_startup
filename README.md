# 本地学习平台（self_startup）

轻量、纯本地的个人工作与学习平台：**规划（默认首页）/ 复盘（含 Agent 看板）/ 信息推荐 / 调研 / 深度学习 / 知识库**，每个板块都有一个可对话的 Agent，直接调用本地 **Claude Code**（`claude -p`），**Codex**（`codex exec`）作为备选。

```bash
./run.sh            # 前台运行：http://127.0.0.1:8780
./run.sh -d         # 后台常驻（日志 data/logs/server.log）
./run.sh stop       # 停止后台服务
```

改动自动生效：`web/` 改了打开的页面会自动刷新（正在输入或对话中时改为提示条）；`app/` 改了由 supervisor 等对话结束后自动重启；后台任务各在独立的 runner 进程里跑（`app/jobrun.py`），重启不等它们、也不会打断；同时最多跑「Agent 并发度」个，机器 CPU 负载或内存紧张时继续排队（设置 `job_guard`），页面显示「机器忙，排队中」。

依赖：`uv`、`claude`（或 `codex`）。数据全部在 `data/`（SQLite `app.db` + markdown/HTML 产物），已 gitignore。

全局设置（页面「设置」或 `data/settings.json`）：人重度干预时间窗（默认 10:00–11:40、13:30–16:50）、Agent 并发度、默认引擎、Claude/Codex 模型、复盘分析目录等。

## 阅读批注

调研报告（综合 / 各引擎原文 / 文档库）、深读笔记、知识库文档、学习计划（总览和每一步）都能划线：选中文字 → 「评论」或「问 Claude」。
被评论的文字高亮，讨论串列在旁边（窄屏在下方）；问 Claude 的回答就地挂在讨论串里，第一问带上全文和划线，追问续接同一个会话；
也可以不划线「问全文」。讨论存在 SQLite（`annotations` / `annotation_msgs`，接口 `/api/annotations`），并同步进知识库 `annotations/`，
之后各板块 Agent 检索知识库时能看到你读过、问过什么。

## 本地知识库（data/kb）

SQLite 管应用状态；每次写操作后，平台自动把内容同步成一棵适合大模型检索阅读的 markdown 树（可随时重建，勿手改）：

```
data/kb/
  README.md            结构与检索说明（给大模型）
  INDEX.md             入口：分类计数、最近更新、全部标签
  daily/YYYY-MM-DD.md  一天的事项与完成、复盘、问题与经验、Agent 效率、当天产出链接（时间线）
  notes/               问题 / 经验 / 洞察 / 想法，一条一个文件
  research/  products/ 调研文档、产品体验
  learn/papers|repos|plans/  论文/项目深读（TL;DR + 笔记 + 全文内嵌）、学习计划（阶段/步骤/理解度/反馈）
  feed/saved.md        点赞 / 收藏的信息
  annotations/         阅读批注：一份材料一个文件，划线原文 + 评论 + 问 Claude 的问答
  tags/<标签>.md       按标签的反向索引
```

- 每个文件带 YAML frontmatter：`id type title date updated tags status url summary`，先看 `summary` 判断相关性再读正文，省上下文。
- 全文检索：SQLite FTS5（trigram，中文可用），`GET /api/kb/search?q=`；也可直接 `rg data/kb`。
- 所有板块 Agent 都能只读访问 `data/kb`，并被告知先查知识库；全局 skill `ss-kb` 让普通 Claude Code / Codex 会话也能用。

## 便捷输入

- 每个页面顶部一个大输入框：Enter 发送、Shift+Enter 换行，按 `/` 随时聚焦；可切换模式（如「记一条 / 问 Agent」「加事项 / 问 Agent」）。
- 输入框下的快捷 chip 一键发常用指令；右侧对话面板随时可开（侧栏「新对话」或最近对话）。

- 每个输入框都有麦克风：说话时文字实时出现在输入框，Esc 取消。其他板块说完填进输入框，改完自己发；讨论板块点一下进入语音通话，再点一下结束：停顿约 0.8 秒自动发送，回复按句读出，读的时候开口就打断朗读和生成。

### 语音转写

录音由 ffmpeg 转成 16k wav，再用本机 whisper.cpp 转文字，音频不出本机，转完即删。需要 `whisper-cli`、`ffmpeg` 和模型文件（`brew install whisper-cpp ffmpeg`）；模型路径和术语提示在设置 `voice.model` / `voice.prompt` 里改，默认读 `~/project/robomaster/whisper.cpp/models/ggml-large-v3-q5_0.bin`。

说话途中用常驻的 `whisper-server` 边录边转（点麦克风时自动启动，闲置 10 分钟退出，平台退出它也退出；只监听 127.0.0.1）。朗读用本机 Kokoro（sherpa-onnx，文字不出本机），语音通话开始时加载，约占 400MB 内存，闲置 10 分钟释放；模型下载 [kokoro-multi-lang-v1_1](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-multi-lang-v1_1.tar.bz2) 解压到 `voice.tts_model`（默认 `~/project/test_feynman/models/kokoro-multi-lang-v1_1`），声音编号和语速在 `voice.tts_sid`（3–57 女声、58–102 男声）/ `voice.tts_speed`（默认 1.3 倍）里改。没有模型或合成失败时退回 macOS `say`（声音在 `voice.tts_voice`）。朗读放在页面里播，让浏览器的回声消除起作用；还能听到自己声音时，转出来的文字和刚念的句子对比，一样就当回声丢掉。讨论是只读的，下一轮的 Claude Code 进程会提前起好（只留一个，5 分钟没用上就停），首句回复能快 2 秒左右。

长录音在停顿处切成不超过 28 秒的段，逐段独立转写，避免 whisper 陷入重复后编造后文；静音、持续噪音和转出来的字幕腔套话会被丢掉。真实链路计时：`python scripts/voice_bench.py <样例目录> [--chat]`，`--chat` 会写对话记录，只在预览实例上跑。

### 通话记录、成本和工具权限

每通电话都留在 `data/voice_calls/<id>/`：`call.m4a`（混音，回听用）、`mic.flac` 和 `bot.flac`（分轨，分析用）、`events.jsonl`（发给百炼和百炼发回的全部非音频事件、本机 Claude 用的工具和答的话，时间和录音对齐），约 1–3MB/分钟，不自动清理。讨论页的「历史通话」可以看内容、点时间跳到那一段回听，也显示每通和总共占多大；「删除」连录音、事件和这通电话说的话一起删（Claude Code 自己的会话日志不动）；「接着聊」开一通新电话，接着同一个讨论和同一个 Claude 会话。

每轮回应的 token 用量记进 `voice_calls`，按设置里的 `voice_rt.price` 算钱（元/百万 token，不扣免费额度，以百炼账单为准）。费用只算百炼：本机 Claude 走订阅，DeepSeek 搜索另计。

通话由百炼实时模型直接接话，寒暄、常识、追问都是它自己答，听完马上开口；它答的常识没有核对过。它有两个工具，调用时由平台补一句「我查一下」或「好，我想一下」：

- `web_search`：天气、价格、新闻这类最新事实。DeepSeek 搜到后整理成一两句念的话，搜到的原文不上云。
- `think_deep`：要用你自己的资料，或者你明确要认真想。交给本机 Claude（`module_models.talk`，默认 Sonnet 5.5），想的时候可以接着聊别的，想好了念 `<spoken>` 里的几句，完整回答只显示在屏幕上，不上云。

工具都登记在 `app/voice_tools.py`，写清每样能碰到什么；讨论页可以开关。关掉的不给模型，通话会如实说做不了。这是应用层的权限，不是操作系统隔离：本机 Claude Code 的只读靠它自己的 `--tools` 限制。

## 结构

```
app/
  main.py        入口：核心接口 + 自动挂载 app/modules/*.py
  agent.py       调用 claude / codex CLI（stream-json），统一事件流，失败自动回退
  chat.py        /api/chat/<module>：每个板块的对话 Agent（SSE，可续聊）
  jobs.py        后台 Agent 任务（调研、解析、拆解等长任务）：排队、暂停 / 继续、审批，完成回调板块 on_job_done
  jobrun.py      单个任务的 runner 进程（独立会话，服务重启不影响）
  annotations.py 阅读批注：划线评论、问 Claude（就地回答、可追问），同步进知识库
  voice.py       /api/voice：本机语音转文字（常驻 whisper-server 实时转写）、朗读
  tasks.py       每日事项 CRUD（规划写、复盘读）
  db.py settings.py
  modules/       一个文件一个板块：router / SCHEMA / agent_context / agent_dirs / on_job_done
web/             无构建的 ES module 前端；web/modules/<板块>.js
skills/<板块>/SKILL.md   板块 Agent 的 skill（对话时注入 system prompt；也可装到全局）
```

**Agent 怎么工作**：对话时平台把 `skills/<板块>/SKILL.md` + 当前数据快照拼成 system prompt，Agent 通过 `curl` 调本平台 API 读写数据（接口见 `/docs`）。

**在普通 Claude Code / Codex 会话里用这些 skill**：

```bash
scripts/install_skills.sh
```

会把各板块 skill 以 `ss-<板块>` 软链到 `~/.claude/skills` 和 `~/.codex/skills`（`--uninstall` 移除）；平台需在运行中。
